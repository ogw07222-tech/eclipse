# ECLIPSE — 현재 직업 설계도

> 갱신: 2026-11-13. 이 문서는 **현재 설계 중인 직업**만 추적한다. 완성 단계인 집행관(백야)은 이 설계도에서 제외한다. **게임 코드, 아트, 구현 이력은 삭제하지 않는다.**
>
> **구현 상태:** 공허 마법사 V3는 설계 초안이다. 게임 코드에 아직 반영하지 않았다. 아래 수치는 별도 명시가 없으면 플레이테스트 전 제안값이다.

## 현재 설계 대상: 공허의 군주 (공허 마법사) — V3

- **등급/역할:** 전설 / 원거리 중력 제어형 / 공중전·공간 압축 특화.
- **외형(신규 기준):** 사용자 승인 기준 이미지의 후드 실루엣, 검보라색 로브·갑주, 차분한 망토, 보랏빛 발광 장식과 손 위에 떠 있는 마도서를 유지한다. 지팡이는 사용하지 않는다. 캐릭터 기본 원본에 블랙홀 및 과도한 공격 이펙트를 합성하지 않는다.
- **아트 규격(신규 기준):** 캐릭터와 마도서를 **함께 그린 96×96px 원본**을 **192×192px 투명 RGBA 캔버스 중앙**에 원본 픽셀 그대로 배치한다(확대·보간 금지). 기본 원본 팔레트는 **투명 포함 최대 30색**을 목표로 한다. 실제 표시 크기·피벗·히트박스는 런타임 연결 전 별도 검증한다.
- **모션/레이어 정책:** 마도서를 독립 스프라이트나 리깅 파츠로 분리하지 않는다. **캐릭터와 마도서는 각 동작 프레임에서 함께 애니메이션**한다. 공허탄, 중력 영역, 차원 가시, 척력 충격파, 궁극기 블랙홀·공간 왜곡 등 **전투 이펙트만 별도 PNG/애니메이션 레이어**로 제작한다. 기존 64×96 기준은 과거 설계이며 신규 아트의 목표 규격이 아니다.
- **기본 이동(변경):** 걷기·달리기 대신 지면에서 살짝 떠 있는 **저공 부유 이동**을 사용한다. 발을 교대로 딛는 달리기 모션은 제작하지 않는다. 고도를 높이는 이동은 점프 없이 패시브 **중력 해방** 비행으로만 수행한다.
- **전투 역할:** 평타 흡인 → 중력장으로 슬로우·지속 피해 → 차원 가시 광역타격 → 주변 척력으로 거리 확보 → 궁극기 공간 붕괴.

### 이동·비행 조작 및 모션 정책

- **일반 점프 삭제:** 이 직업에는 별도의 점프 동작, 점프 키포즈, 점프에 의한 상승 단계가 없다. 고도 상승은 오직 패시브 **중력 해방**을 사용한다.
- **기본 대기:** 발이 지면에 닿지 않는 낮은 높이에서 천천히 상하 부유한다. 후드와 망토는 절제된 움직임을 보이고, 마도서는 캐릭터 원본과 한 프레임 안에서 함께 움직인다.
- **기본 좌우 이동:** 걷기·달리기 대신 같은 낮은 높이에서 수평으로 미끄러지듯 이동한다. 다리의 달리기 사이클은 사용하지 않고, 로브·망토의 지연과 몸의 기울기 등으로 이동감을 표현한다.
- **비행:** 조이스틱 위 방향 유지로 비행 게이지를 소모하며 상승·체공한다. 위 입력을 해제하거나 게이지가 고갈되면 낮은 기본 부유 높이로 하강한다. 일반 점프로 전환하지 않는다.
- **비행 중 행동:** 좌우 이동, 평타, 스킬 사용을 허용한다. 공격 동작에서도 캐릭터·마도서는 하나의 액터 프레임으로 유지하고 공격 이펙트만 별도 레이어로 처리한다.
- **게이지 제안값 유지:** 최대 비행 4초, 초당 25% 소모, 지상(기본 저공 부유 상태) 초당 20% 회복. 게이지 소모·회복 전환의 정확한 조건은 구현 전 검증한다.
- **구현 주의:** 이는 공허의 군주 전용 설계다. 다른 직업의 점프 조작을 전역 삭제하지 않는다. 지형 충돌·낭떠러지·기본 부유 높이·비행 상승속도·입력 처리는 아직 미구현·미검증이다.

### 모션 아트 디렉션 — 무심하고 시크한 공간 지배자 (2026-11-13)

> **캐릭터는 절제하고 이펙트는 압도한다.** 움직임이 작다는 이유로 모든 프레임을 동일하게 만들지 않는다. 손끝·손목·후드 방향·마도서 기울기·망토 지연으로 의도를 읽을 수 있는 고유 키포즈를 만든다. 아래 시간과 각도는 **모션 제작 초기 제안값**이며 확정된 게임 판정 프레임이 아니다.

- **공통 자세:** 몸통은 대체로 수직, 고개를 살짝 숙여 상대를 내려다보는 인상. 큰 상체 회전, 점프, 달리기, 과장된 팔 휘두르기, 반복적인 전신 반동은 금지.
- **손·마도서:** 한 손의 작은 지시만으로 공간이 반응한다. 마도서는 캐릭터와 **같은 액터 PNG 프레임** 안에서 부유하며 페이지·각도만 조용히 변화한다. 별도 마도서 레이어·리그를 만들지 않는다.
- **후드·망토:** 두꺼운 천의 관성을 표현해 움직임이 약간 늦게 따라온다. 가벼운 천처럼 지속적으로 요란하게 펄럭이지 않는다.
- **리듬:** 짧은 준비 동작 → 의도적인 미세 정지 → 분리된 대규모 이펙트 → 무심한 복귀. 공격의 크기를 신체 동작 크기로 표현하지 않는다.
- **대기:** 느린 1~2px 상하 부유(제안), 시선과 어깨는 거의 고정. 마도서가 작은 위상차로 따라온다.
- **좌우 부유 이동:** 몸을 진행 방향으로 아주 약하게 기울이고 로브 끝이 뒤따른다. 발을 딛거나 교차하지 않는다.
- **패시브 비행:** 손을 살짝 펼치고 수직으로 상승. 상승·체공·하강을 별도 포즈로 구별하되 슈퍼맨식 비행이나 점프 포즈는 금지.
- **평타 — 공허탄:** 손가락을 짧게 펴거나 손목을 돌려 발사 지시. 발사체·흡인 효과는 분리.
- **스킬 1 — 중력 영역:** 손바닥을 아래로 낮추고 마도서가 살짝 펼쳐짐. 중력장 전개 후 캐릭터는 평상 자세로 돌아와 부유 이동 가능.
- **스킬 2 — 차원 가시:** 목표 방향으로 두 손가락 또는 손바닥을 조용히 향하게 함. 가시는 캐릭터 밖 공간에서 별도 이펙트로 발생하며 큰 찌르기 동작은 없음.
- **스킬 3 — 중력 척력:** 손을 가볍게 오므렸다 펴거나 손목을 짧게 뒤집음. 충격파만 크게 확산하고 몸통은 안정적.
- **궁극기 — 특이점 붕괴:** 마도서가 조용히 펼쳐지고 한 손을 천천히 들어 손가락을 오므림. 시전 중 긴 정적과 고정된 실루엣을 유지하다 마지막에 손을 가볍게 쥐며 공간 붕괴. 캐릭터 자체의 과장된 전신 반동 금지.
- **피격·사망:** 일반 피격은 짧은 어깨·후드 흔들림, 강한 피격은 잠깐 자세가 무너지는 정도. 사망 시 부유 제어가 사라지며 서서히 낙하하는 대비를 사용.
- **검수:** 각 스킬의 실루엣이 서로 구분되어야 하며, 손·팔이 몸통과 해부학적으로 연결되어야 한다. 캐릭터+마도서 일체형, 96×96 원본/192×192 투명 캔버스, 30색 이하 기준을 유지한다. 이펙트는 별도 레이어. 실제 60FPS 목표와 고유 포즈 수는 제작 단계에서 별도 검증한다.

### 넉백저항 통합

- 공허탄 흡인과 스킬 3 척력 모두 기존 `knockbackResistance()`를 사용한다. 저항이 높을수록 이동 거리가 줄어든다.
- 빨강 슬라임은 크게, 초록 슬라임은 보통, 보라 슬라임은 약하게 이동. 보스는 높은 저항.
- **적이 밀리거나 끌려가는 동안에도 공격을 강제 중단하지 않는다.**

### 궁극기 연출 — 독자적 암흑 우주 / 사건의 지평선

1. **0.00–0.40초:** 공중 마법서가 펼쳐지고 주변 전장의 색과 소리가 사라지며 몬스터 움직임 정지.
2. **0.40–1.00초:** 배경이 끝없는 암흑 우주처럼 변하고 미세한 보라색 특이점 출현.
3. **1.00–1.65초:** 주변 별빛이 중앙으로 늘어지며 사건의 지평선 형성. 적들이 중심으로 압축됨(넉백저항 반영).
4. **1.65–2.00초:** 블랙홀이 하나의 점으로 수축하고 짧은 정적 후 백보라 섬광·광역 피해. 전장 복구.

참고 감성은 압도적인 정적과 무한한 공간감이지만, 특정 작품의 구체적 화면·상징·연출을 복제하지 않고 ECLIPSE 고유의 블랙홀 연출을 제작한다.

### 제외된 구상

- 과거 V1/V2 패시브 **공허 낙인 / 군집 붕괴(적 밀집 시 받는 피해 증가)**는 폐기.
- 스킬 3 **차원 도약 / 공간 전이 / 방어막** 후보는 현재 설계에서 제외, **중력 척력**으로 교체.
- 스킬 1 **바닥 고정형 중력 우물**은 자기 중심 이동형 **중력 영역**으로 교체.

- 공허탄 흡인의 정확한 거리·속도와 넉백저항 보정.
