# ECLIPSE — 현재 직업 설계도

> 갱신: 2026-11-05. 이 문서는 **현재 설계 중인 직업**만 추적한다. 완성 단계인 집행관(백야)은 이 설계도에서 제외한다. **게임 코드, 아트, 구현 이력은 삭제하지 않는다.**
>
> **구현 상태:** 공허 마법사 V3는 설계 초안이다. 게임 코드에 아직 반영하지 않았다. 아래 수치는 별도 명시가 없으면 플레이테스트 전 제안값이다.

## 현재 설계 대상: 공허의 군주 (공허 마법사) — V3

- **등급/역할:** 전설 / 원거리 중력 제어형 / 공중전·공간 압축 특화.
- **외형:** 검보라색 갑주와 찢어진 로브, 어두운 후드, 공중에 떠 있는 마법서, 손의 소형 블랙홀. **지팡이는 사용하지 않으며, 마법서도 손으로 들지 않는다.**
- **아트:** 네이티브 64×96 픽셀 캐릭터 프레임 기준. 캐릭터·마법서·공허탄·중력장·공간 왜곡은 독립 PNG 레이어로 구성할 방향.
- **기본 이동:** 원거리 계열 저속, 비행 패시브로 입체적인 위치 제어.
- **전투 역할:** 평타 흡인 → 중력장으로 슬로우·지속 피해 → 차원 가시 광역타격 → 주변 척력으로 거리 확보 → 궁극기 공간 붕괴.

### 비행 조작 정책

- 기존 게임에서 독립 점프 버튼을 제거했던 정책을 유지한다. **조이스틱 위 방향 유지**를 점프/비행 입력에 매핑하는 것을 우선 설계.
- 짧은 위 입력은 일반 점프, 공중에서 위 입력 유지 시 게이지 소모 비행. 손을 떼면 하강; 게이지 고갈 시 비행 종료.
- 게이지는 지상 회복. 비행 중 좌우 이동, 평타, 스킬 사용 허용.
- 현재 전투 입력 코드에서 실제로 비행 유지 입력이 안정적으로 처리되는지는 구현 단계에서 검증 필요.

### 넉백저항 통합

- 공허탄 흡인과 스킬 3 척력 모두 기존 `knockbackResistance()`를 사용한다. 저항이 높을수록 이동 거리가 줄어든다.
- 빨강 슬라임은 크게, 초록 슬라임은 보통, 보라 슬라임은 약하게 이동. 보스는 높은 저항.
- **적이 밀리거나 끌려가는 동안에도 공격을 강제 중단하지 않는다.**

### 궁극기 연출 — 독자적 암흑 우주 / 사건의 지평선

1. **0.00–0.40초:** 공중 마법서가 펼쳐지고 주변 전장의 색과 소리가 사라지며 몬스터 움직임 정지.
2. **0.40–1.00초:** 배경이 끝없는 암흑 우주처럼 변하고 미세한 보라색 특이점 출현.
3. **1.00–1.65초:** 주변 별빛이 중앙으로 늘어지며 사건의 지평선 형성. 적들이 중심으로 압축됨(넉백저항 반영).
4. **1.65–2.00초:** 블랙홀이 하나의 점으로 수축하고 짧은 정적 후 백보라 섬광·광역 피해. 전장 복구.

참고 감성은 압도적인 정적과 무한한 공간감이지만, 특정 작품의 구체적 화면·상징·연출을 복제하지 않고 ECLIPSE 고유의 블랙홀 연출을 제작한다.

### 제외된 구상

- 과거 V1/V2 패시브 **공허 낙인 / 군집 붕괴(적 밀집 시 받는 피해 증가)**는 폐기.
- 스킬 3 **차원 도약 / 공간 전이 / 방어막** 후보는 현재 설계에서 제외, **중력 척력**으로 교체.
- 스킬 1 **바닥 고정형 중력 우물**은 자기 중심 이동형 **중력 영역**으로 교체.

### 남은 결정 및 검증

- 비행 상승속도, 체공 제어, 게이지 회복 조건, 공중 스킬 모션 및 HUD 가시성.
- 공허탄 흡인의 정확한 거리·속도와 넉백저항 보정.
- 스킬 2 가시 범위·높이·히트박스.
- 궁극기 중 적 이동/공격/투사체 정지 범위와 보스 면역, 데미지 및 화면 전환.
- 기획 승인 전 전투 로직·아트·스프라이트·APK를 변경하지 않는다.
