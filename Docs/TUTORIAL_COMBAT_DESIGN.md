# ECLIPSE — 전투 튜토리얼 설계 (1단계, 초안)
Status: **설계 초안 — 소유자 확인 전. 구현·빌드·플레이 검증 없음.**
Scope: `Docs/TUTORIAL_PROLOGUE_FLOW.md`의 1단계(조작 연습)만. 2~9단계는 건드리지 않는다.
원칙: 대사/텍스트 없음, 실전 속에서 가르침, "사용설명서" 금지.

## 소유자 결정 (2026-11-25)
1. **범위: 기본 + 교체 + 공간의 지배자 스택 상호작용.** 이동, 점프, 회피(대시), 기본 공격, 스킬 1·2 (섬광의 집행자) → **교체(스왑) 테스트** → **공간의 지배자로 스택과 상호작용**하는 법. (확정 2026-11-25: 처음 초안의 "집행자만"은 폐기.)
2. **시간 정지 대신 슬로모션.** 완전히 멈추지 않고 느려진다. **실패하면 직전으로 되감기** 후 다시 시도한다.
3. **설계 문서 먼저.** 이 문서를 확인받은 뒤에만 구현한다.

> 참고: 기존 `TUTORIAL_PROLOGUE_FLOW.md` 1단계("두 전설 클래스를 모두 체험")와 이번 범위는 방향이 같다. 비트 구성이 확정되면 그 문서의 1단계 행을 이 설계에 맞게 고친다.

## 입력 잠금 (2026-11-25, 소유자 지시)
튜토리얼 비트 동안에는 **그 비트의 버튼만** 동작한다. 이동(좌우)은 항상 가능하고, 점프는 점프 비트에서만, 대시·공격·스킬·스왑은 해당 비트에서만 눌린다. 비트 사이 정리 구간에는 이동만 된다. (구현됨: `StoryDirector::practiceInput`)

## 핵심 연출 규칙
### 슬로모션 (위기 순간)
- 조건이 맞으면 월드 속도를 **약 0.3배**로 낮춘다 (정지 아님: 적 동작, 플레이어 이동 모두 느리게 계속 진행).
- 플레이어는 느린 상태에서 **그 순간의 정답 버튼**을 누른다. 누르면 속도가 즉시 1배로 돌아오며 기술이 나간다.
- 슬로모션은 **최대 약 1.5초(실시간)** 유지. 그 안에 못 누르면 그대로 1배로 복귀하고, 아래 "실패"로 처리한다.
- 연출: 화면 가장자리 푸른 테두리, 정답 버튼 강조, 기술이 닿는 범위/경로 표시(화살표·점선·원). 텍스트 없음.

### 실패 → 되감기
- **실패 정의**: 회피 구간에서 피격, 슬로모션 시간 초과, 기술이 목표에 닿지 못함.
- 되감기 = **그 비트가 시작된 순간**의 상태(플레이어·적 위치/체력/공격 모션·쿨다운·빛구슬)로 복귀. 고정 시간(2초 등)으로 정하지 않는다. 기존 회귀 연출(8단계의 시간 역행 모티프: 가로 빛줄기, 푸른 플래시)을 짧게(약 0.6초) 재사용한다.
- 되감기 후 같은 위기 순간이 다시 온다. 횟수 제한 없음. (소유자 결정: 3번 연속 실패 시 슬로모션을 강화하는 도움 규칙은 **두지 않는다**.)
- 되감기는 튜토리얼 안에서만 존재한다. 게임 오버 화면, "실패" 표시는 쓰지 않는다 (플레이어 HP는 계속 바닥 1로 유지).

## 비트 (한 판의 연속 전투, 중간 리셋 없음)
| # | 가르치는 것 | 상황 | 위기 순간 / 정답 | 성공 | 실패(되감기) |
|---|---|---|---|---|---|
| 1 | 이동 + 점프 | 빈 길, 빛기둥이 앞에 | 슬로모션 없음. 이동 스틱·점프 버튼이 부드럽게 깜빡임 | 빛기둥 도달 + 점프 1회 | 없음 |
| 2 | 회피 (대시) | 병사 1명이 땅에서 올라와 다가옴 | 병사가 칼을 휘두르기 직전 슬로모션. 대시 경로(화살표)가 병사를 관통해 표시됨. **정답: 대시** | 맞지 않고 휘두름이 끝남 | 맞음 / 시간 초과 |
| 3 | 기본 공격 + 빛구슬 | 같은 병사를 쓰러뜨릴 수 있는 상태 (HP 바닥은 처치 허용으로 해제) | 슬로모션 없음. 공격 버튼 깜빡임 | 빛구슬 3개 | 없음 (병사 약하므로 자연 진행) |
| 4 | 스킬 1 — 돌진 | 병사 3명이 정면에서 일렬로 몰려옴 | 병사들이 사거리에 들어오면 슬로모션. 돌진 경로(직선)와 맞는 적들이 표시됨. **정답: 스킬 1** | 돌진이 적 2명 이상 관통 | 아무도 못 맞힘 / 시간 초과 |
| 5 | 스킬 2 — 명령 | 멀리 사제 + 병사 2명이 흩어져 있음 | 빛구슬 3개가 차 있을 때 슬로모션. 구슬이 각 적에게 향하는 점선 표시. **정답: 스킬 2** | 창이 적중해 표식이 남음 | 구슬이 없거나 적이 범위 밖 |

| 6 | 교체 (스왑) | 수문장 기사 등 단단한 적이 등장 | 슬로모션 후 **스왑** 버튼 강조 | 공간의 지배자로 교체됨 | 시간 초과 |
| 7 | 공간의 지배자 — **스택 상호작용** | **미정 (아래 확인 요청 참고)** | 미정 | 미정 | 미정 |

각 비트의 마지막은 짧은 정리 구간(적 소탕, 약 1초)을 둔다. 이 7개가 끝나면 기존 2단계(성 입구)로 이어진다. (비트 1~5 순서·구성은 소유자 확인 완료. 이동·점프는 회피와 합치지 않고 별도 비트로 둔다.)

## 시스템 요구사항 (구현 시)
- **슬로모션**: 현재 `Combat::timeScale`(0=정지)을 0.3 등 연속값으로 쓴다. 플레이어 입력은 그대로 받아야 하므로, 지금처럼 `Actions{}`로 막지 않는다. 애니메이션 속도도 같은 배율.
- **되감기**: **비트가 시작되는 순간**에 체크포인트를 한 번 저장한다(주기 저장 불필요). 저장 대상은 플레이어, 적 목록, 투사체/창, 쿨다운, 빛구슬. 복귀 시 그대로 덮어쓴다. `Combat` 전체 복사가 가능한지(포인터/참조 멤버 없는지) 먼저 확인해야 한다.
- **판정**: 성공/실패 조건은 전투 상태에서 직접 읽는다 (예: 피격 횟수 `hurtSerial` 비교, 돌진 관통 수, 표식 `lightMark`).
- **적**: 기존 실제 AI 사용. 튜토리얼 중에는 체력 하한을 두되, 비트 3과 각 비트의 정리 구간에서는 쓰러질 수 있어야 한다.
- 되돌릴 일 (이번 구현에서 제거): 스왑/공간의 지배자 비트, 시간 완전 정지 연출, 현재 16비트 구조.

## 비트 7 — 월식 반응 (소유자 확정: 속성 반응, 2026-11-25) — **초안, 구현 전**
튜토리얼이 가르치려면 반응 규칙이 먼저 있어야 한다. 아래는 `COMBAT_SKILLS_AND_STATUS_DESIGN.md` v0.3("섬광이 먼저 + 암흑 후속 = 월식: 빛의 흡수·인력·지연 붕괴")을 코드 가능한 규칙으로 옮긴 **제안**이다. 모든 수치는 플레이테스트 전 추정치.
- **속성**: 섬광의 집행자 = 섬광(빛 표식 `lightMark`, 명령 창이 5초간 부여). 공간의 지배자 = 암흑(배경 설계가 암흑 우주/특이점).
- **발동 조건**: 빛 표식이 남은 적에게 **지배자의 직접 피해**(탄환, 가시, 밀쳐내기, 특이점)가 적중. 장판 틱 같은 지속 피해와 집행자 자신의 공격은 발동시키지 않는다. 같은 적에서 재발동은 1.5초 쿨.
- **소비**: 맞은 적의 표식을 소비한다.
- **흡수 (0~0.25초)**: 반경 220px 안 다른 적의 표식도 모두 소비해 중심으로 빨려 들어간다. 소비한 표식 수 N을 센다.
- **인력 (0.25~0.85초)**: 중심에 검은 원(가장자리 금빛). 반경 220px 적들이 중심으로 끌려온다(넉백 저항 적용, 바닥 없는 곳으로는 안 끌림).
- **지연 붕괴 (0.85초)**: 수축 후 폭발. 반경 160px에 피해 `기본 40 + 12 × N` (일반 적 기준 추정치), 중심 적은 1.3배. 월식 피해는 반응을 다시 일으키지 않는다.
- **읽는 법 (텍스트 없음)**: 표식이 작은 흰 점이 되어 중심으로 모이는 것, 검은 원의 크기가 N에 비례하는 것, 폭발 때 모인 빛이 사방으로 퍼지는 것으로 "빛을 쌓을수록 크게 터진다"가 전달된다.
- **튜토리얼 흐름**: 비트 5(명령)에서 적들에게 표식이 이미 남아 있다 → 비트 6(스왑)으로 지배자 → 비트 7: 슬로모션에 "표식 붙은 적들 + 지배자 스킬 버튼"만 강조 → 한 방에 월식이 터지면 성공. 표식이 사라진 뒤(5초 경과)에는 되감기 지점(비트 시작)에서 표식을 다시 부여한다.
- **구현 항목 (후속)**: `Combat`에 월식 우물 목록과 단계 갱신, 지배자 피해 경로 4곳(`stepSpace`의 탄환/가시/밀쳐내기/특이점)에서 표식 검사, 표식 아이콘 표시, 이펙트 아트(검은 원, 수축·폭발, 표식 점) — 이펙트는 도트 키 포즈부터 직접 작업.
- **이번 비트에서 다루지 않음**: 일식(암흑 먼저 + 섬광 후속), 기본 원소와의 반응(없음), 보스 저항.

## 확인 요청 (남은 것)
1. 월식의 4단계(흡수 → 인력 → 지연 붕괴)와 "표식이 많을수록 커진다" 규칙이 원하는 느낌인가요?
2. 지배자의 직접 피해 4가지(탄환, 가시, 밀쳐내기, 특이점) 모두 발동시켜도 되나요, 아니면 특이점/가시 같은 일부만?
3. 월식 피해량과 반경은 지금 추정치예요. 일단 튜토리얼 적이 한 방에 정리되는 수준으로 시작해도 되나요?

## 구현 현황 (2026-11-25): 6비트 압축판
소유자 지시로 구현은 6비트다. 이동·점프(비콘까지 걷고 점프) → 회피(시간 정지, 대시) → 기본 공격(빛구슬 3개) → 돌진(시간 정지) → 명령(표식 남기기) → **월식**(스왑 시간 정지 → 지배자 가시 시간 정지 → 표식 적에게 월식 발동). 점멸·심판·지배자 나머지 스킬은 가르치지 않는다. **슬로모션과 되감기 구현됨**: 반응 순간은 0.3배 슬로모션(최대 1.5초)이고 맞는 버튼을 누르면 즉시 1배로 돌아와 기술이 나간다. 시간 초과·회피 실패(피격)·기술이 아무것도 못 맞힘이면 0.6초 되감기 연출 후 **비트 시작 순간의 전투 전체**(`Combat` 스냅샷)로 복귀해 같은 비트를 다시 한다. 횟수 제한·도움 규칙 없음.
