## 조작 및 스프라이트 연결

- [집행자 아트·이펙트](../Art/flash-executioner/README.md): 승인된 actor/effect PNG, 모션 시간, 이벤트, 런타임 경로.
- [집행자 버튼 감사](EXECUTOR_INCANDESCENT_FX_BUTTON_AUDIT.md): 공격 J/Z, 스킬1 K/X, 스킬2 U, 스킬3 O, 궁극기 P; Shift 대시, L/C/Tab 교체.
- [네이티브 엔진](../native-engine/README.md): 게임 조작과 포팅 기록. 일부 설명은 과거 기준임.
- [필수 작업 규칙](../AGENTS.md): 수동 키포즈, 60FPS 고유 포즈 목표, PNG 원본/런타임 동기화, 사용자 승인 없는 GitHub Actions 금지.

## 문서 관리 원칙

1. **설계 / 구현 / 아트 승인 / 실제 기기 검증**을 별도 상태로 기록한다.
2. 기존 문서를 삭제하거나 수치를 임의로 통합하지 않는다. 이 색인은 링크와 상태만 관리한다.
3. 신규 직업 스킬을 추가할 때 기준 문서 링크, 스킬 슬롯, 상태, 최종 갱신일을 이 표에 추가한다.
4. `README.md`는 프로젝트 입구, 이 파일은 캐릭터·스킬 탐색 입구로 유지한다.
5. 검증하지 않은 구현·아트·기기 테스트를 완료로 표시하지 않는다.
