# 손목·발목 표식 추적 검토

원본 PNG를 변경하지 않고, 눈으로 식별한 손목·발목에 검토용 표식을 붙였다. 자동 관절 인식이 아니다. 수동 좌표에는 대략 ±2 원본 픽셀의 불확실성이 있다. 투명 영역에서 2px 안에 보이는 실루엣을 찾지 못한 좌표는 제외했다. 이 조건은 표식의 시각적 위치를 검사할 뿐, 관절/부위 식별의 정확성을 보증하지 않는다.

- 파랑: 무기를 쥔 손목. 빨강: 구분 가능한 반대 손목.
- 초록/노랑: 발 A/B의 구간별 추적. 이 2D 원본만으로 해부학적 왼발·오른발을 확정하기 어려워 좌우로 단정하지 않았다.
- 가려짐/겹침으로 확정할 수 없는 좌표는 null. 보간하거나 빈 구간을 연결하지 않는다. 특히 백야와 마법사의 반대 손은 확정하지 못해 표시하지 않았다.

## 결과

| 대상 | 표식 추적 결과 | 판정 범위 |
|---|---|---|
| 일반 기사 약베기 | 11자세의 무기 손목과 두 발을 표시. 반대 손은 7자세만 식별. 연결 자세를 포함한 경로를 생성 | 빠른 베기에서 손목 변위가 큰 것만으로 순간이동/오류라 판단할 수 없다. 자연스러움 통과 판정 안 함 |
| 마법사 점프·낙하 | 16자세의 무기 손목, 발 A14/B9자세 표시. 옷/다리에 가려지는 구간 제외 | 공중 시전·착지와 해부학적 좌우 추적은 미완료. 자연스러움 통과 판정 안 함 |
| 백야 달리기 | 32자세의 무기 손목, 발 A27/B21자세 표시. 가려진 구간에서 궤적을 끊음 | 지면선의 발끝 외곽이 앞뒤로 흐르는 구간이 있어 미끄러짐 의심. 자세별 접지 타이밍과 원본 발 궤적 검토 필요 |

### 백야 접지 외곽의 시간 기반 측정

현재 표시 설정(280단위/s, 280단위/주기, 원본1px당 월드1.85px)과 실제 60Hz 선택 샘플의 표시 시점을 사용했다. 고정된 지면선(원본 y88)에서 가장 오른쪽 불투명 픽셀을 발끝 외곽의 대용점으로 추적했다.

| PNG 구간 | 실제 샘플 시간차 | 원본 발끝 X | 몸 이동을 포함한 발끝 외곽의 월드 변위 |
|---|---:|---|---:|
| 89→91 | 66.67ms | 57→42 | -9.08px (뒤로) |
| 112→114 | 50ms | 39→36 | +8.45px (앞으로) |

변위 = 이동속도 × 경과시간 + 원본 좌표 변화 × 표시 배율. 두 구간에서 외곽은 지면선에 있지만 월드 X가 고정되지 않는다. **이 수치는 발끝 외곽을 접점으로 본 기하학적 진단이며 실제 발-지면 충돌 측정은 아니다.** 신발 변형으로 외곽 픽셀도 바뀔 수 있다. 처음 계산한 이상적인32FPS 간격에서는 -10.25/+11.95px였지만, 최종 보고/그림은 60Hz의 실제 자세 선택 시각을 적용한 -9.08/+8.45px를 쓴다.

관절 표식과 지면 외곽 검사는 별개다. 불확실한 관절 좌표로 접지 변위를 계산하지 않았다. 속도/가속도 수치만으로 자연스러움 점수를 만들지 않았다. MP4를 생성했지만 연속 재생 시청을 했다고 주장하지 않는다. 표식과 시간별 궤적을 시각적으로 검토했다.

## 산출물

- `weak_marked.mp4`, `mage_marked.mp4`, `white_marked.mp4`: 실제60Hz 선택 순서에 표식을 덧그린 검토용 영상. 백야는 몸을 따라가는 카메라에서 지면이 현재 이동속도로 흐르는 기준선을 추가했다. 나머지는 포즈 공간이며 실제 점프 높이/지형/전투 이펙트를 재현하지 않는다.
- `white_landmark_review.png`: 선택한 자세의 표식과 시간별 발끝/관절 궤적.
- `landmarks.json`: 수동 좌표와 미확인 구간. `measurements.json`: 측정값과 원본 SHA256.

재현:

```sh
python3 native-engine/tools/review_changed_animations.py
python3 native-engine/tools/review_landmarks.py
```

원본 SHA256이 실행 전후 같음을 확인했다. 이미지/게임플레이/재생 설정은 수정하지 않았다. 전체 게임 실행·사용자 테스트 모음·GitHub Actions는 실행하지 않았다.
