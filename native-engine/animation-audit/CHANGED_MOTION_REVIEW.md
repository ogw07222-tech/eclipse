# PR #72 변경 사항 후속 점검

이번 범위는 기존 PR에서 바꾼 약베기·마법사 점프/낙하·백야 달리기와 비교 도구다. 전체 캐릭터 재작화 완료 보고가 아니다.

## 확인 및 수정

| 변경 대상 | 확인 결과 | 처리 | 남은 검증 |
|---|---|---|---|
| 기사 약베기 | 60Hz `Animation::step` 샘플에서 11고유 PNG 자세가 선택됨. 캐릭터는 새 표시 매핑을 쓰지만 `swordTrail()`은 기존 `a.frame`을 참조해 어긋날 수 있었음 | 캐릭터와 검 궤적이 같은 `knightWeakFrame(posePhase)`를 사용하도록 수정. 11자세는 유지하면서 누락됐던 원본 5번 전방 연결 자세와 7번 후속 자세를 복원하고 유사한 대기/회복 자세를 대신 제외. 타격·대미지·공격 타이머는 유지 | 실제 SDL 합성 화면과 실시간 자연스러움 |
| 마법사 점프·낙하 | 상승 16–23, 낙하 24–31을 모두 참조함. 기존 6→8 매핑에서 빠지던 자세 참조가 복원됨 | 8자세 매핑을 `mageAirPose()`로 모아 렌더러와 오프라인 샘플러가 같은 계산 사용. 새 PNG 없음 | 실제 착지·경사/발판·공중 시전 전환, 실시간 자연스러움 |
| 백야 달리기 | 60Hz·280단위/s에서 88–119의 32자세가 1초에 선택됨. 위치가 멈추면 위상이 고정됨 | 32장·280단위 주기 유지. 프레임 순서 비교만으로 지면 접촉 품질을 확정할 수 없어 추가 임의 보정 없음 | 원본 발 궤적의 구간별 이동량 차이와 지면 미끄러짐, 장비/아날로그 속도별 자연스러움 |
| 비교 뷰어 | 데이터/PNG 경로와 전후 표시 매핑을 소스 대조함 | 기존 뷰어 유지. 소유자가 제공한 브라우저 없는 도구를 별도로 연결 | 브라우저 UI 실행 검증 없음 |
| 점검 보고서 | 36개 클립 참조 범위/빈 프레임을 재점검함 | 검 궤적 동기화 내용과 후속 점검 링크 갱신 | 미완료 항목은 그대로 미완료 |

## 사용한 재생 도구와 확인 근거

사용자가 제공한 `eclipse_sprite_tool.py`를 수정 없이 `native-engine/tools/`에 포함했다. 소스 PNG는 변경하지 않았다. 해당 도구의 프레임 비교표·이미지 차이 분석·MP4 출력을 사용했다. GIF의 10ms 시간 양자화는 정확한 FPS 증거로 쓰지 않았다.

`review_changed_animations.py`는 실제 C++ `Animation::step`, `knightWeakFrame`, `mageAirPose`를 사용하는 작은 샘플러를 컴파일한다. 전체 게임이나 SDL 렌더러를 빌드/실행하지 않는다. MP4는 실제 60Hz 샘플을 그대로 보존하고, 비교표에서만 연속 홀드를 생략한다. 이는 새 자세나 신규 PNG 프레임 수를 늘리는 작업이 아니다.

이번 실행 결과:

- C++17 / `-Wall -Wextra -Werror`로 샘플러 컴파일 및 실행 성공.
- 약베기: 13개 60Hz 표시 샘플 / 11고유 자세. 선택 순서: `112,114,116,117,117,118,119,120,122,122,124,126,127`.
- 히트스톱: 접촉 자세 118번이 유지됨.
- 마법사: 상승 8·낙하 8자세가 선택됨. 원래 중력 가속도 1250과 발사 속도 -650을 사용한 속도 샘플이며 실제 지형 충돌을 재현하지 않음.
- 백야: 60개 60Hz 샘플 / 32고유 자세. 10회 추가 샘플에서 위치를 고정했을 때 이동 위상 고정 확인.
- 사용자의 도구로 전후 재생 파일과 순서별 프레임 비교표 생성. 변경된 PNG 참조 순서를 비교표로 직접 확인.
- 36클립 정적 PNG 범위 점검과 `git diff --check` 수행.

**MP4를 생성한 것과 실시간 재생을 시청한 것은 다르다.** 이번에 확인한 것은 순서별 프레임 비교표와 코드가 선택한 60Hz 자세다. 전체 게임 실행, SDL 합성 이펙트, 실제 기기 재생, 발 접촉/미끄러짐과 실시간 자연스러움은 검증하지 않았다. 기존 사용자 테스트 모음과 GitHub Actions는 실행하지 않았다.

재현 명령:

```sh
python3 native-engine/tools/review_changed_animations.py
```

Pillow, C++17 컴파일러가 필요하다. FFmpeg가 있으면 MP4도 생성한다. 결과는 `native-engine/review/changed/`에 쓴다. 이 명령은 자동으로 실행되지 않으며 네트워크를 사용하지 않는다.
