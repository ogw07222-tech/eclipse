# ECLIPSE — 공간의 지배자 스킬·모션 통합 설계서

- 작성 기준: 2026-11-13
- 근거: `ogw07222-tech/eclipse`의 `main`, `Docs/CURRENT_CLASS_DESIGN.md` (모션 디렉션 반영 커밋 `5773c343`)
- 문서 상태: **설계안**. 실제 게임 구현·모션 PNG 제작·기기 검증 완료를 뜻하지 않음.
- 명칭 주의: 튜토리얼에는 **공간의 지배자**, 상세 V3 직업 설계에는 **공허의 군주(공허 마법사)**로 표기됨. 이 문서는 공간의 지배자 제작용으로 V3를 정리한 것이며 명칭의 공식 통합은 별도 확인 필요.

## 1. 캐릭터 아트 기준

| 항목 | 제작 기준 |
|---|---|
| 외형 | 어두운 후드, 검보라색 로브·갑주, 차분하고 무거운 망토, 절제된 보라색 발광 |
| 마도서 | 손 위에 떠 있는 마도서. **캐릭터 원본과 일체형**, 별도 분리·리깅 없음 |
| 지팡이 | 사용하지 않음 |
| 기본 캐릭터 원본 | **96×96px** |
| 최종 프레임 캔버스 | **192×192px**, 투명 RGBA, 96×96 원본을 중앙 배치, 보간 확대 금지 |
| 팔레트 | 투명 포함 **최대 30색** 목표 |
| 이펙트 | 공허탄·중력장·차원 가시·척력 충격파·궁극기 공간 왜곡 등을 **별도 레이어**로 제작 |
| 시점 | 횡스크롤 게임에 맞는 측면 시점, 일관된 신체 비율 |

> 캐릭터와 마도서는 매 모션 프레임에 함께 포함한다. 캐릭터 기본 원본에 블랙홀·광역 충격파 같은 공격 이펙트를 합성하지 않는다. 96×96은 아트 제작 규격이며, 실제 게임 내 월드 스케일·피벗·충돌 판정은 별도 확정한다.

## 2. 모션 연출 철학

**캐릭터는 무심하고 시크하게, 이펙트는 압도적으로.** 강함을 큰 몸짓이 아닌 작은 손짓과 주변 공간의 반응으로 보여준다.

- 몸통은 대체로 수직. 후드는 약간 아래로 향하고, 상대를 내려다보는 듯한 인상.
- 손목·손가락·시선·마도서의 작은 각도 변화로 기술을 구분한다.
- 망토는 무겁고 천천히 따라오며 과장되게 펄럭이지 않는다.
- 동작 리듬은 **작은 예비 동작 → 짧은 정적 → 강한 별도 이펙트 → 담담한 복귀**.
- 손·팔의 연결, 신체 비율, 무기/마도서의 위치 일관성을 프레임마다 확인한다.
- 절제된 움직임은 정지 프레임 복제를 뜻하지 않는다. 모든 액션에 구별되는 고유 키포즈가 필요하다.

## 3. 기본 동작 목록

| 동작 | 액터 모션 | 별도 이펙트 / 주의 |
|---|---|---|
| 대기(Idle) | 지면 바로 위에서 천천히 상하 부유. 어깨·후드 안정, 마도서는 약간 다른 위상으로 흔들림 | 1~2px 부유 폭은 **초기 제안값** |
| 좌우 이동(Hover Move) | 걷기·달리기 대신 수평으로 미끄러짐. 몸이 아주 조금 기울고 로브 끝이 뒤따름 | 발 교차·착지·달리기 사이클 없음 |
| 비행 상승(Flight Rise) | 손을 조금 펼치고 조용히 상승 | 패시브 비행 게이지 사용 |
| 비행 체공(Flight Hold) | 공중에서 안정적으로 자세 유지 | 공격·스킬 사용 가능 |
| 비행 하강(Flight Descend) | 입력 해제 또는 게이지 고갈 시 기본 부유 높이로 복귀 | **점프 및 점프 모션 없음** |
| 피격(Hurt) | 어깨·후드의 짧은 흔들림 | 과장된 전신 회전 지양 |
| 사망(Death) | 부유 제어를 잃고 천천히 떨어짐 | 다른 모션과 대비되는 무게감 |

**조작:** 위 방향 입력 유지로 패시브 `중력 해방` 비행. 별도 점프 동작을 만들지 않는다. 다른 직업의 점프를 전역 삭제하는 정책은 아니다.

## 4. 스킬셋 및 전투 효과

아래 수치는 원본 V3 문서의 **플레이테스트 전 제안값**이다.

| 슬롯 | 이름 | 전투 효과 | 제안 수치 |
|---|---|---|---|
| 평타 | **공허탄** | 소형 블랙홀 구체 발사, 피해와 약한 흡인. 적의 넉백저항 반영 | 발사 간격 0.55초, 흡인 반경 약 100px, 이동 약 20~40px(저항 전) |
| 패시브 | **중력 해방** | 위 입력 유지 시 상승·체공, 해제 시 기본 부유 높이로 하강. 공중 공격 가능 | 최대 4초, 초당 25% 소모, 기본 저공 부유 상태에서 초당 20% 회복 제안 |
| 스킬 1 | **중력 영역** | 자신을 중심으로 따라오는 중력장, 주변 적 둔화·지속 피해. **강제 흡인 없음** | 반경 150px, 3초, 둔화 30%, 0.5초마다 기본 피해 6, 쿨타임 7초 |
| 스킬 2 | **차원 가시** | 지정 방향의 공간에서 가시 발생, 광역 피해 및 공중 적 타격 | 쿨타임 7초, 상세 범위·높이·히트박스 미확정 |
| 스킬 3 | **중력 척력** | 자신 주변 원형 충격파, 적 밀어냄. 넉백저항 반영, 적 공격 강제 취소 없음 | 반경 180px, 발동 0.15초, 기본 피해 12, 쿨타임 5초 |
| 궁극기 | **특이점 붕괴** | 거대 블랙홀의 광역 흡인·압축·붕괴 피해 | 쿨타임 20초, 약 2초 연출 |

## 5. 스킬별 액터 모션과 분리 이펙트

| 스킬 | 액터의 고유 동작 | 별도 이펙트 |
|---|---|---|
| 공허탄 | 손가락을 짧게 펴거나 손목을 돌려 발사 지시. 마도서가 미세하게 기울어짐 | 소형 공허 구체, 궤적, 적중 및 흡인 |
| 중력 영역 | 손바닥을 아래로 낮추고 마도서가 살짝 펼쳐짐. 발동 뒤 평상 부유 자세로 복귀 | 캐릭터를 따라오는 중력장, 범위·지속 피해 표시 |
| 차원 가시 | 목표 방향으로 두 손가락 또는 손바닥을 조용히 향함. 큰 찌르기 동작 없음 | 지정 공간에서 굵은 차원 가시 발생, 파열·피격 효과 |
| 중력 척력 | 손을 가볍게 오므렸다 펴거나 손목을 짧게 뒤집음. 몸통은 안정 | 원형 척력 충격파, 공간 굴절·밀려남 |
| 특이점 붕괴 | 마도서가 펼쳐지고 한 손을 천천히 들어 손가락을 오므림. 긴 정적 유지 후 손을 가볍게 쥠 | 전장 암전, 특이점, 사건의 지평선, 흡인, 붕괴 섬광 |

> 스킬별 세부 액터 동작은 **2026-11-13 모션 아트 디렉션에서 제안한 제작 방향**이며, 확정된 게임 판정 타이밍이나 완료된 스프라이트를 뜻하지 않는다.

## 6. 궁극기 — 특이점 붕괴 타임라인

| 시간 | 액터 동작 | 이펙트·전장 변화 |
|---|---|---|
| 0.00~0.40초 | 마도서가 조용히 펼쳐짐, 손을 조금 듦 | 전장의 색과 소리가 사라지고 몬스터 움직임 정지 |
| 0.40~1.00초 | 시전 자세를 거의 움직이지 않고 유지 | 암흑 우주 배경, 미세한 보라색 특이점 |
| 1.00~1.65초 | 손가락을 서서히 오므림 | 별빛이 중앙으로 늘어남, 사건의 지평선 형성, 적 압축 |
| 1.65~2.00초 | 손을 가볍게 쥐고 담담하게 복귀 | 한 점으로 수축, 짧은 정적, 백보라 섬광·광역 피해, 전장 복구 |

궁극기 화면 연출의 정적·압도감은 유지하되, 특정 작품의 장면을 그대로 복제하지 않는다.

## 7. 제작 순서 및 검수 체크리스트

1. 기준 96×96 원본의 실루엣·팔레트·마도서 위치를 확정하고 192×192 투명 캔버스 규격을 고정한다.
2. **대기 → 저공 부유 이동 → 비행 상승/체공/하강**의 고유 키포즈를 만든다. 점프·달리기 모션은 만들지 않는다.
3. 평타·스킬 1~3·궁극기의 액터 키포즈를 각각 독립적으로 제작한다. 같은 손짓 프레임을 단순 재사용하지 않는다.
4. 캐릭터+마도서가 한 프레임에 포함되는지, 손·팔 연결과 시점이 일관적인지 확인한다.
5. 공격 이펙트는 별도 PNG/애니메이션으로 제작하고, 액터 모션의 접촉·발동 타이밍과 맞춘다.
6. 네이티브 해상도와 최근접 확대 화면에서 픽셀 뭉개짐, 팔레트 초과, 프레임 간 떨림, 캐릭터 크기 변화, 발광 과다를 점검한다.
7. 실패 항목의 원인을 기록하고 해당 프레임·이펙트를 수정한 후 재검증한다. **60FPS 고유 포즈 목표**는 실제 완성 프레임을 검증한 뒤에만 달성했다고 표기한다.
8. 최종 사용자 승인 전에는 게임 런타임 자산을 임의로 교체하지 않는다.

## 8. 미확정 사항

- 공간의 지배자와 공허의 군주 명칭 통합 여부
- 비행 상승·하강 속도, 기본 부유 높이, 낭떠러지·지형 충돌 정책
- 공허탄의 정확한 흡인 속도와 넉백저항 계수
- 차원 가시의 범위·높이·히트박스
- 궁극기 중 적·투사체 정지 범위와 보스 면역
- 각 모션의 프레임 수, 실제 타격·시전 프레임, 피벗과 런타임 연결
