# 백야의 집행자

ECLIPSE 전설 직업. 개발 중 사용한 캐릭터 작업명은 Flash Knight.

| 시트 | 프레임 | 순서 |
| --- | --- | --- |
| `run-16.png` | 16 | 4열 × 4행, 행 우선, 16 → 1 반복 |
| `slash-15.png` | 15 | 4열 × 4행, 행 우선, 마지막 칸 비움 |

두 PNG는 동작 검토용 원화다. 인게임 적용 전 64×96 투명 프레임으로 정리하고 발 기준점과 검끝을 검증한다. 기본 기사의 아틀라스와 별도로 관리한다.

베기 2~3컷은 투구가 칼날을 가린다. 4컷에서 칼날이 위로 돌아 나오고, 5~7컷에서 검이 전방으로 뻗는다. 7컷을 타격 동기화 기준으로 잡고, 실제 적용 시 검끝 좌표와 판정 범위를 맞춘다. 검기와 광창은 캐릭터 시트와 분리한다.
