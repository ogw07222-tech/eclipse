# ECLIPSE Forest PNG Pack v1

40 individual pixel art PNG assets, grouped by type.

All non-background/terrain items have RGBA transparency. Forest silhouettes and terrain tiles use opaque PNGs.
This pack is sourced from a generated concept sheet and processed into individual sprites. Please visually QA alpha edges before publishing.

Use `manifest.json` for image sizes and pivot choices. Static by default; avoid global grass sway.
