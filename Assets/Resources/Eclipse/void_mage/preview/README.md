# 공간의 지배자 — 저공 부유 이동 전용 시안

새로 추가한 것은 **달리기 대체 이동 모션 시안**뿐이다. 기존 캐릭터/마도서/이펙트 PNG와 27장 키 포즈, 기존 공격·스킬 시안은 수정하지 않았다.

- [브라우저에서 부유 이동 확인](./move_hover.html) (GitHub 파일 미리보기 대신 로컬 HTTP 서버로 실행)
- 원본: `../character.png` + `../grimoire.png`의 **idle 0–2 키 포즈**.
- 프레임: 12 표시 프레임, 0.7초 기준 약 17.14FPS. 이동속도는 게임의 원거리 계열 설정을 유지한다.
- 방식: 상하 진폭 ±1px, 마도서 최대 ±2px의 지연 이동, 점프/비행으로 이어지는 가벼운 저공 부유.
- 달리기 대신 부유 이동. 발 접지/교차 보행 없음.
- 시안 페이지에서 12프레임 투명 PNG 시트 저장 가능. 생성 시트는 원본 이미지의 위치·포즈를 조합한 임시 시안이며 **12장의 새 수작업 포즈가 아님**.
- 검사 필요: 원본 idle 키 포즈 간 관절 튐, 투명 픽셀, 마도서 기준점, 좌우 대칭, 루프 접합.
- 스킬 모션·판정·쿨타임·게임 이동속도 변경 없음. SDL3에 미통합.

로컬 미리보기:
```sh
cd ~/eclipse
python -m http.server 8765
# http://127.0.0.1:8765/Assets/Resources/Eclipse/void_mage/preview/move_hover.html
```

주의: 사용자의 규칙에 따라 GitHub Actions나 게임 테스트는 실행하지 않는다.
